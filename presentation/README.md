# Presentation

`financial_sentiment_finetuned.pptx` is the current editable six-slide submission deck. It follows the user-supplied reference's navy/teal design, typography, workflow diagram, result panels, comparison tables, and conclusion layout. The earlier `financial_sentiment_revised.pptx` was open and locked during the update, so the new version uses this separate filename. The original extended deck remains available as `financial_sentiment.pptx`.

The conclusion slide includes the verified [live application](https://financial-sentiment-akshatog.streamlit.app/) as a clickable link.

The six slides cover the project overview, transformer workflow, three model routes, evaluation results, fine-tuning and checkpoint selection, and conclusion with Unit 4 mapping. The tables on slides 3 and 5 and the workflow on slide 2 remain native editable objects. Speaker notes include source references, data preparation details, training provenance, and presenter context.

The project fully fine-tunes `yiyanghkust/finbert-pretrain`, updating all 109,754,115 BERT and classification-head parameters on 3,385 training rows. The completed Tesla T4 run took about 7 minutes 50 seconds across 3 epochs and 636 optimizer steps. Validation macro F1 was 81.40%, 81.92%, and 81.87% across the three epochs, selecting epoch 2 at checkpoint 424. The 725 validation rows select the checkpoint. The 726 test rows stay outside training and selection.

On the same test split, majority prediction scores 59.37% accuracy and 24.83% macro F1, TF-IDF + logistic regression scores 75.76% and 71.94%, and student fine-tuned FinBERT scores 85.12% and 84.46%. Fine-tuning gains 9.37 percentage points in accuracy and 12.52 points in macro F1 over TF-IDF. These are descriptive results on one seeded split. The published Prosus checkpoint's 88.15% / 87.51% result is a separate reference with known PhraseBank sentiment-training exposure, so it is not a fair unseen-data benchmark.

The numbers come from `outputs/dataset_audit.json`, `outputs/evaluation.json`, `outputs/finetuning/evaluation.json`, `models/finbert_finetuned/training_manifest.json`, and `models/finbert_finetuned/training_history.json`. The builder preserves the first per-epoch validation result because the final history entry re-evaluates the restored best checkpoint.

The current builder is `build_reference_deck.mjs`. It uses JavaScript and `@oai/artifact-tool`, edits a copy of the supplied reference, reads current evidence files, and exports reference and final slide previews to the ignored `.cache/presentation/` folder. It validates the six-slide count, package integrity, template fonts, slide geometry, and native table ownership before copying the validated file to `financial_sentiment_revised.pptx`, or to `financial_sentiment_finetuned.pptx` if the former is locked. It takes the original reference PPTX path as its first argument (or `REFERENCE_DECK`) and needs the Codex bundled authoring runtime, optionally selected by `CODEX_ARTIFACT_RUNTIME`. The friend's source file is not redistributed in this repository. `build_deck.mjs` builds the earlier extended version. The application itself does not require the presentation authoring dependency.
